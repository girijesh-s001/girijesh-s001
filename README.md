### `02 / things I've been building`

<br>

#### `→ Ancient Tamil OCR`

A recognition pipeline for handwritten and ancient Tamil characters.

The work combines **OpenCV preprocessing, character segmentation,
CNN-based recognition**, and experimentation with low-resource
character recognition.

One of the research directions I'm currently pursuing is palm-leaf
manuscript OCR.

```text
~2,200 glyphs
10 manuscripts
319 glyph classes

88.10% character accuracy
11.90% character error rate
```

The pipeline has also been benchmarked against:

`PaddleOCR PP-OCRv5` · `DeepSeek-OCR` · `Pixtral-12B` · `Donut` · `PARSeq`

---

#### `→ Visual Forensics`

Documents can lie.

So I built a system that tries to find **where** they lie.

The project combines:

`OCR forensics`
`ORB / RANSAC`
`copy-move detection`
`Error Level Analysis`
`ResNet34 anomaly detection`

Instead of returning only:

```text
"tampered"
```

the system produces evidence:

```text
      ┌───────────────────────┐
      │     suspicious area   │
      │        ███████        │
      │        ███████        │
      │                       │
      │ confidence: 0.xx      │
      └───────────────────────┘
```

Heatmaps, bounding boxes and confidence scores make the result
easier to inspect.

---

#### `→ Tanglish → தமிழ்`

A small NLP project with a simple purpose:

**make romanized Tamil readable as Tamil.**

```text
epdi iruka?
      ↓
எப்படி இருக்க?
```

Built with Python and NLP-based normalization.
